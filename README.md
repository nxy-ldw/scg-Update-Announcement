# 🏛️ 收藏馆 | 个人多功能收藏展示平台

欢迎提交 Issue 来交换您的看法和对脚本的更多建议！
作者：南京信息职业技术学院   一屿Yy
请尊重 Apache2.0 协议与开源精神，二次开发保留原作者信息。

收藏馆是一款轻量化、高颜值、高定制化的个人多功能收藏展示网页平台，专为个人内容收纳、展示与分享设计。支持多类型内容收藏、自定义主题美化、布局切换、一键分享等核心能力，界面精致流畅、性能优异，适合个人日常使用、内容展示与轻量化建站。
项目由一屿文化工作室开发维护，持续迭代优化用户体验与页面性能，主打简洁优雅的视觉设计与实用全面的收藏管理功能。
✨ 项目核心亮点
- 高颜值视觉体系：内置8套精美主题，每套主题配备专属渐变背景、动态装饰特效，支持悬浮动效、微光光晕、图案层叠加，视觉层次丰富。
- 全品类收藏支持：一站式收纳书签、歌曲、摘抄、电影、书籍、图片、倒计时、待办八大类内容，覆盖个人日常收藏全部场景。
- 极致页面性能：深度优化CSS渲染与DOM交互，减少GPU开销、规避高频重排重绘，动画流畅不卡顿，适配全设备浏览。
- 灵活自定义布局：支持列表模式、对称布局双模式切换，管理员可自定义图文内容、上传图片，自由度极高。
- 便捷内容分享：全内容支持一键分享，适配所有收藏品类，可直接分享至好友聊天，自带专属内容图标标识。
- 全端自适应：完美适配电脑、手机等不同尺寸设备，移动端专属优化布局，浏览体验统一流畅。
📦 最新版本更新（2026.08.06）
本次版本为功能性大更新，聚焦视觉美化、性能优化、功能拓展、体验修复四大方向，详细更新内容如下：
🎨 主题中心全面美化
- 全部8套主题新增渐变背景预览与装饰性图案层，提升整体质感
- 专属主题动态特效：星空主题星星点缀、樱花主题花瓣光斑、海洋主题波纹光晕
- 主题卡片新增Hover缩放动效、当前主题标识、锁定状态标识
- 深浅色主题差异化优化：深色主题搭配紫粉微光、落日主题叠加暖色光晕
- 全局叠加主题专属图案层，页面视觉统一性、美观度大幅提升
⚡ 全站性能深度优化
- 降低背景模糊渲染强度，大幅减少GPU渲染开销，低配设备也能流畅运行
- 顶栏、标签栏、播放器核心模块添加CSS隔离，缩小页面重排重绘范围
- 滚动监听加入帧节流处理，规避高频DOM操作导致的卡顿问题
- 限制卡片入场动画数量与延迟上限，避免大量数据加载时页面卡顿
- 优化CSS过渡规则，替换全局过渡为精准属性过渡，提升渲染效率
🔗 全内容分享功能上线
- 新增通用一键分享功能，支持收藏馆内所有品类内容分享
- 覆盖八大内容类型：书签、歌曲、摘抄、电影、书籍、图片、倒计时、待办
- 核心卡片新增专属分享入口，操作便捷无门槛
- 支持选择好友直接发送至聊天界面，分享流程极简
- 聊天消息自动匹配内容图标，区分不同收藏类型，辨识度拉满
❤️ 布局升级与功能更名
- 原「个人空间」正式更名为「支持作者」，功能定位更清晰
- 管理后台新增对称布局模式，与传统列表模式自由切换
- 对称布局采用四分对称图文排版，视觉均衡高级
- 支持图片自定义上传（自动压缩）、链接导入、文字内容自由编辑
- 用户端自动适配后台布局设置，无需手动切换
🐛 已知问题修复
- 修复下拉菜单、搜索框显示空白的CSS裁剪问题
- 优化好友界面渲染逻辑，解决重复刷新、闪屏故障
- 优化好友码展示规则，仅展示未使用好友码，界面更整洁
🚀 快速部署
环境要求
纯静态网页项目，无需后端、无需数据库，支持所有静态网页托管平台。
部署方式
1. 下载项目源码，获取 index.html 主文件
2. 上传至 GitHub 仓库
3. 绑定 Cloudflare Pages、Vercel、Netlify 等静态托管服务
4. 重要提示：Cloudflare Pages 用户更新项目后，需重新上传 index.html 文件，确保前端更新生效
💻 项目技术栈
- 前端基础：HTML5 + CSS3 + 原生JavaScript
- 字体支持：Google Noto Sans SC 开源中文字体（400-800字重全覆盖）
- 视觉技术：渐变配色、模糊磨砂质感、CSS动画、Hover交互动效
- 性能优化：CSS隔离、帧节流、精准过渡动画、渲染开销精简
- 适配方案：响应式布局，适配移动端/桌面端全尺寸设备
